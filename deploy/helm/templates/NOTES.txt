{{ if not .Values.networkPolicy.enabled -}}
⚠  networkPolicy.enabled is false. The API port (POST /internal/events) is
   reachable by any pod in the cluster, and /metrics is unauthenticated and
   reachable by any pod too. Enable in production:
     networkPolicy.enabled: true
   Ensure the ingress controller namespace label and event_consumer's own
   pod-label selector match:
     ingressControllerNamespaceSelector: {{ .Values.networkPolicy.ingressControllerNamespaceSelector | toJson }}
     eventConsumerPodSelector: {{ .Values.networkPolicy.eventConsumerPodSelector | toJson }}

{{ end -}}

   production.
